Thank you for your interest in contributing.

This repository is maintained as a professional portfolio. Contribution is by invitation only.

If you are a recruiter or potential collaborator and would like to discuss changes or improvements, please open an issue or contact the repository owner via GitHub.

Guidelines for invited contributors:
- Create a feature branch named `feature/short-description` or `fix/short-description`.
- Keep commits small and focused; use clear commit messages.
- Run any checks locally before opening a PR (e.g., verify the Streamlit demo starts and notebooks render).
- Include rationale for significant changes in the PR description.
